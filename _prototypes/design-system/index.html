Notes / Inconsistencies

Documented for future cleanup — not addressed in this page.

  • Styles are duplicated across prototypes (one-pager/cst copy); no shared component CSS package.
  • No formal spacing scale; layout uses ad-hoc pixel values alongside a few CSS variables.
  • Button variants mix generic ui-button-* classes with feature-prefixed classes (toolbar, modal, org).
  • No radio buttons, dedicated badge component, loading spinners, or global .ui-button:disabled style.
  • Modal styling split between .profile-modal-* (20px radius) and .target-modal-* (10px radius).
  • Checkbox patterns differ: .filter-check vs .location-row-checkbox.
  • Error/success states exist only on gate errors and screenshot toasts — not on form fields.
  • Global h1 is defined but unused in CST app HTML.
